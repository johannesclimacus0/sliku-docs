# Маршрутизация

## Метод и путь

Маршрут говорит приложению, какой обработчик вызвать для нужного адреса и HTTP-метода.
Маршруты стартера собраны в `routes/api.php`.

```php
$app->get('/users/{user:[0-9]+}', UserController::class . ':show');
```

Здесь `get()` задаёт HTTP-метод, `/users/{user:[0-9]+}` определяет путь, а `UserController::class . ':show'` указывает на метод контроллера. Выражение `[0-9]+` разрешает в параметре `user` только цифры.

В разработке Vue обращается к `/api/...`, а Vite удаляет префикс перед передачей запроса.
При прямом обращении в бекэнд, префикс `/api` добавлять не нужно.

## Группы и middleware

В Slim маршруты можно объединять с помощью `$app->group()`. Группа позволяет задать общий префикс и подключить middleware сразу к нескольким обработчикам.

Для ограничения частоты запросов используются middleware, зарегистрированные в контейнере под строковыми идентификаторами, например `rate_limit.login`. 
При добавлении новых маршрутов можно использовать существующий ограничитель или настроить отдельный.

## Параметры маршрута и привязка сущностей

`RouteEntityBindingStrategy` переносит аргументы маршрута в атрибуты запроса и готовит именованные параметры метода.
Если имя параметра совпало с placeholder, а тип - сущность Doctrine, стратегия загрузит ее через `EntityManagerInterface::find()`.

```php
public function show(
    User $user,
    ServerRequestInterface $request,
    ResponseInterface $response,
): ResponseInterface
```

Для `{user}` стратегия загрузит `User` по переданному идентификатору.
Если записи нет, появится `EntityNotFoundException`, а клиент получит 404.

Для такой привязки важно совпадение имён: `{user}` соответствует `$user`, а `{id}` сам по себе не связывается с аргументом `$user`. 
Поиск выполняется по идентификатору сущности, а не по email или какому-либо другому полю.

## Имена маршрутов

Маршруту можно присвоить имя с помощью `setName()`. 
Это помогает обращаться к нему независимо от самого URL. В некоторых случаях имя используется внутренними компонентами приложения.
