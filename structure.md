# Структура проекта

Дерево показывает основные точки входа и расположение компонентов, а не каждый файл проекта.

## Организация PHP-кода

PHP-код разделён между двумя основными каталогами:

- `app/` содержит общую инфраструктуру стартера: обработку HTTP-запросов, middleware, очереди, события, кэш, файловое хранилище и другие механизмы, доступные всему приложению.
- `src/` предназначен для функциональности самого приложения. Здесь находятся сущности Doctrine и модули, в которых разрабатываются новые возможности.

Оба каталога используют пространство имён `App\`.

### Модули приложения

Функциональность приложения организована в модулях внутри `src/Modules/`.

В стартере уже есть два модуля:

- `Auth` отвечает за регистрацию, вход, обновление сессий, подтверждение электронной почты и сброс пароля.
- `Account` содержит работу с профилем, аватарами, каталогом пользователей, ролями, уведомлениями и демонстрационными операциями.

Внутри модулей контроллеры обрабатывают HTTP-запросы, классы `Input` описывают и проверяют входные данные, сервисы выполняют основные сценарии, а репозитории работают с данными. Например, изменение профиля проходит через `UserController`, `ProfileInput` и `ProfileService`, а `UserView` формирует представление пользователя для API.

```text
src/
├── Entity/
│   └── User.php                # Сущность пользователя
└── Modules/
    ├── Auth/                   # Вход, регистрация и сессии
    │   ├── Controllers/        # HTTP-запросы авторизации
    │   ├── Http/               # Текущий пользователь из запроса
    │   ├── Input/              # Входные данные и правила валидации
    │   ├── Mail/               # Подготовка писем
    │   ├── Repositories/       # Данные сессий
    │   └── Services/           # Сценарии регистрации и входа
    └── Account/                # Профиль и работа с пользователями
        ├── Commands/           # Консольные команды модуля
        ├── Controllers/        # HTTP-запросы кабинета
        ├── Events/             # События пользователя
        ├── Handlers/           # Обработчики заданий
        ├── Input/              # Входные данные и правила валидации
        ├── Jobs/               # Сообщения для очереди
        ├── Listeners/          # Реакция на события
        ├── Mail/               # Подготовка писем
        ├── Notifications/      # Уведомления аккаунта
        ├── Repositories/       # Чтение и сохранение данных
        ├── Security/           # Правила доступа модуля
        ├── Services/           # Сценарии работы с профилем
        └── UserView.php        # Представление пользователя для API
```

## Регистрация компонентов

Некоторые компоненты требуют явной регистрации.

| Компонент                | Где подключается                    |
|--------------------------|-------------------------------------|
| HTTP-маршруты            | `routes/api.php`                    |
| Консольные команды       | `config/registrations/commands.php` |
| События и слушатели      | `config/registrations/events.php`   |
| Настройки сервисов       | `config/settings/`                  |
| Определения зависимостей | `config/definitions/`               |

`config/container.php` собирает определения зависимостей, а `AppFactory` создаёт HTTP-приложение и подключает маршруты и middleware.

Подробнее о создании и внедрении зависимостей рассказано в разделе [Контейнер зависимостей](/docs/{{version}}/container).

## Структура фронтенда

Интерфейс находится в `frontend/`. Это самостоятельное Vue-приложение со своими зависимостями и настройками Vite.

Основной код интерфейса расположен в `frontend/src/`:

```text
frontend/src/
├── components/          # Переиспользуемые компоненты интерфейса
├── composables/         # Общая логика на Composition API
├── layouts/             # Каркасы страниц
├── router/              # Маршруты и переходы
├── services/            # Запросы к API и клиентские сервисы
├── stores/              # Состояние Pinia
├── views/               # Страницы
├── App.vue              # Корневой компонент
├── main.ts              # Создание и запуск Vue-приложения
└── style.css            # Общие стили
```
