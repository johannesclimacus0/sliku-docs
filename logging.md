# Логи и диагностика запросов

В стартере для записи сообщений используется Monolog, доступный через стандартный интерфейс `Psr\Log\LoggerInterface`. 
Его можно получить через DI.

Создание логгера настроено в `config/definitions/logger.php`, а параметры логирования находятся в `config/settings/logging.php`.

## Запись сообщений

Чтобы записывать события приложения, достаточно добавить `LoggerInterface` в конструктор класса:

```php
use Psr\Log\LoggerInterface;

final class ReportLog
{
    public function __construct(private LoggerInterface $logger) {}

    public function ready(int $userId, string $reportId): void
    {
        $this->logger->info('Report ready', [
            'user_id' => $userId,
            'report_id' => $reportId,
        ]);
    }
}
```

## Уровни логирования

Переменная `LOG_LEVEL` определяет минимальный уровень записываемых сообщений. По умолчанию используется `info`.

| Уровень   | Когда использовать                                     |
|-----------|--------------------------------------------------------|
| `debug`   | Подробная информация для локальной отладки             |
| `info`    | Обычные события и успешно выполненные операции         |
| `warning` | Неожиданные ситуации, не обязательно приводящие к сбою |
| `error`   | Ошибки, из-за которых операция не была выполнена       |

Для просмотра логов приложения и обработчика очереди в Docker выполните:

```bash
./run logs --tail=100 app worker
```

## Профилирование с Clockwork

Для более подробной диагностики в стартере предусмотрен Clockwork. Он включается при сочетании настроек:

```dotenv
APP_ENV=local
APP_DEBUG=true
```

Интерфейс доступен по адресу `http://localhost:8080/clockwork/`. С его помощью можно изучать диагностические данные запросов и искать медленные операции.
